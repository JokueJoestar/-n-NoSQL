Hệ thống thu thập lỗi ứng dụng — Cassandra & Redis

1. Gửi log lỗi thử

Chức năng: nhận log → Redis (rate-limit, dedup, gom nhóm) → Cassandra (ghi bền)
0Ghi chi tiết
0Chỉ đếm (dedup)
0Bị chặn (429)

2. Top lỗi hôm nay

Nguồn: Redis Sorted Set errtrend — ZREVRANGE

3. Log mới nhất

Nguồn: Redis List recent_errors — LRANGE

    4. Nhóm lỗi và tổng số lần xảy ra

    Nguồn: Cassandra error_groups + error_group_counter — cập nhật sau mỗi lần worker đồng bộ (1 phút)

    5. Tra cứu log theo thiết bị

    Nguồn: Cassandra error_logs_by_device (ngày hôm nay, UTC)

    6. Xu hướng đã lưu theo ngày

    Nguồn: Cassandra error_trend_daily (snapshot do worker chụp)
